# Scalar charge $c_A$

Real amplitude of the oscillating point source in [[EFT with oscillating scalar sources]].

**How it is fixed**: match the EFT prediction for the asymptotic field of an isolated star (with [[Gravitational dressing]], Eq. 19) to the numerically computed [[Boson star]] profile.

Value for the paper's model ($G\mu m_A=0.713$, $\omega_A=0.439\mu$):
$$\sqrt{G}\,\mu\, c_A = 1.608$$

Enters [[Scalar potential w_scalar]] as $c_1c_2$. Equal-mass case: $c_1=c_2$.
