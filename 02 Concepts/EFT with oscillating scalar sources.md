# EFT with oscillating scalar sources

Each [[Boson star]] → point particle (worldline $z_A(\tau_A)$) carrying a **harmonically varying complex scalar charge**:

$$s_A(\tau_A) = c_A\,e^{i\epsilon_A\omega_A\tau_A + i\Phi_A}$$

Action (Eq. 9):
$$S_{\rm EFT} = \int\frac{\sqrt{-g}}{2}\left\{\frac{R}{8\pi G} - \left[\nabla\bar\varphi\nabla\varphi + \mu^2\bar\varphi\varphi\right]\right\} - \sum_A\int\left\{m_A - 2\pi\left[\varphi(z_A)\bar s_A + \bar\varphi(z_A)s_A\right]\right\}d\tau_A + S_{\rm GF}$$

- Only $\mu^2|\varphi|^2$ kept: $\varphi^4,\varphi^6$ terms decay exponentially faster.
- **New feature**: the oscillating source (standard scalar-tensor EFTs have static charges).
- $c_A$ fixed by matching → [[Scalar charge]].

**LO impulse** (scalar exchange diagram, Eq. 11):
$$\Delta p_1^\nu = -\frac{8\pi\tilde\mu c_1c_2}{\sqrt{\gamma^2-1}}K_1(\tilde\mu b)\frac{b^\nu}{b}\cos\Phi_{21} - \frac{8\pi c_1c_2}{\sqrt{\gamma^2-1}}(\omega_1\gamma-\omega_2)\check u_2^\nu\sin\Phi_{21}K_0(\tilde\mu b)$$
- 1st term (transverse) → $\chi^{\rm scalar}_{\rm LO}$, Eq. 12
- 2nd term (longitudinal) → **non-conservative** when $\Phi_1\neq\Phi_2$; negligible in NR here.

Leads to [[Scalar potential w_scalar]]; higher orders → [[Gravitational dressing]].
