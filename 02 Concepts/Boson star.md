# Boson star

Self-gravitating, stationary configuration of a **complex scalar field** minimally coupled to gravity (Kaup 1968).

$$S = \int\frac{\sqrt{-g}}{2}\left\{\frac{R}{8\pi G} - \left[g^{\mu\nu}\nabla_\mu\bar\varphi\nabla_\nu\varphi + V(|\varphi|)\right]\right\}d^4x$$

**Harmonic ansatz**: $\varphi(t,r) = A(r)\,e^{i(\epsilon\omega t + \Phi)}$
- $A(r)$: real radial profile
- $\omega$: frequency; $\Phi$: initial phase
- $\epsilon=+1$ BS, $\epsilon=-1$ anti-BS (opposite Noether charge, identical spacetime)

**Solitonic potential**: $V = \mu^2|\varphi|^2(1-2|\varphi|^2/\sigma_0^2)^2$ — allows high compactness (between NS and BH).

Model used in [[Damour Jain Sperhake 2025 - BS scattering]]:
- $\sqrt{G}\sigma_0=0.2$, $\sqrt{G}A_{\rm ctr}=0.17$
- $r_{99}=5.58\,Gm$, $G\mu m = 0.713$, $\omega = 0.439\mu$
- tidal deformability $\Lambda\approx7$ → [[Tidal potential w_tid]]

Far from the star the field decays like a Yukawa tail with $\bar\mu=\sqrt{\mu^2-\omega^2}$ → defines the [[Scalar charge]].

Key point: $\epsilon$ and $\Phi$ are invisible for a single star but matter when two overlap → [[Scalar potential w_scalar]].
