# Internship with Tamanna Jain — boson-star scattering

Obsidian vault and working repo for my internship on boson-star (BS) binaries,
analytic (EOB / PM / EFT) vs numerical-relativity scattering.

Supervisor: Tamanna Jain (DAMTP, Cambridge)

## How to use

1. Clone this repo.
2. In Obsidian: **Open folder as vault** → select the repo folder.
3. Start at [[00 Home]].

## Layout

| Folder | What goes there |
|---|---|
| `00 Home.md` | Map of the whole vault — start here |
| `01 Papers/` | One note per paper (summary, method, my questions) |
| `02 Concepts/` | One note per idea, linked from papers with `[[wikilinks]]` |
| `03 Meetings/` | One note per supervisor meeting |
| `04 Log/` | Daily / weekly research log |
| `05 Questions/` | Running list of open questions |
| `06 Code/` | Scripts and notebooks |
| `Templates/` | Note templates (set as Obsidian's template folder) |
| `99 Attachments/` | Figures, PDFs, images |

## Obsidian settings

- Settings → Core plugins → **Templates** on, template folder = `Templates`
- Settings → Files and links → attachment folder = `99 Attachments`
- Equations use `$...$` / `$$...$$` (built-in MathJax)
